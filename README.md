# NaviHier
App zur einfachen Navigation in Gebäuden


## Was ist was?
Im Ordner '[host](host)' befindet sich ein Python Projekt, mit dem die Daten eines 'facilities' Ordners erstellt und verwaltet werden.


In den Ordnern '[server](server)' und '[client](client)' ist die Version von Server und Frontend mit expressjs & static-page HTML enthalten.

Im Ordner '[svelte](svelte)' wird momentan eine Version von Server und Frontend mit [sveltekit](https://svelte.dev/docs/kit/creating-a-project) erstellt.
